## [1.0.0] - 2026-11-01

### Added
- Add the `whchoi` marketplace, installed with `claude plugin marketplace add whchoi98/aws-deck` and `claude plugin install aws-deck@whchoi`
- Add `aws-ppt-skills` for 16:9 seminar decks on the 2026 AWS black and white templates, with Korean speaker scripts, native editable charts, and AWS diagrams
- Add `consulting-ppt-white-ppt` for dense consulting-report decks whose accent color is derived from the customer's logo
- Add `pptx-template-fill` for filling a supplied template in place, unifying fonts, replacing chart data, and checking the result for leftover text and overflow
